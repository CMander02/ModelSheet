## 实现状态说明

### 图例

- ✅ CLI: 在 CLI parser.py 中实现
- ✅ Web: 在 Web formatters.ts 中计算
- ❌: 未实现
- ⚠️: 实现有问题或不完整

### 需要修复的问题

1. **architecture**: 当前使用 `model_type` (如 `qwen2`)，建议改用 `architectures[0]` (如 `Qwen2ForCausalLM`)
2. **numLayers/numHeads/hiddenSize**: 需要添加备用键名回退 (`n_layer`, `n_head`, `n_embd`, `d_model`)
3. **numKvHeads**: 若无此键，应默认等于 `numHeads`
4. **activation**: 需要添加备用键名 `activation_function`
5. **gqaRatio**: 当前保留 2 位小数，建议改为 1 位
6. **hasChatTemplate**: 当前仅检查键是否存在，应检查值是否为非空字符串

### 需要新增的字段

1. **arxivUrl**: 从 API `tags` 中提取 `arxiv:xxxx` 格式的标签，转换为 URL
2. **numSharedExperts**: MoE 模型的共享专家数 (`n_shared_experts`)
3. **firstKDenseReplace**: DeepSeek 风格 MoE 模型的前 K 层 Dense 替换数
4. **moeIntermediateSize**: MoE 专家的 FFN 中间层宽度

### 字段来源分布

```
CLI 解析 (parser.py):
├── Metadata: id, name, provider, huggingfaceUrl, createdAt
├── Direct: vocabSize, numLayers, numHeads, numKvHeads, hiddenSize,
│           embeddingDim, intermediateSize, activation, normEps,
│           attentionDropout, numExperts, numExpertsPerToken,
│           eosToken, bosToken
├── Logic: contextLength, isMoe, totalParameters, activeParameters,
│          normType, positionEncoding, hasChatTemplate, isAdapter
└── Calc: mlpFactor, gqaRatio

Web 计算/格式化 (formatters.ts):
├── formatParameters: totalParameters, activeParameters
├── formatContextLength: contextLength
├── formatNumber: vocabSize, hiddenSize, intermediateSize, etc.
├── formatDecimal: mlpFactor, gqaRatio, normEps
├── formatBoolean: isMoe, hasChatTemplate, isAdapter
└── formatDate: createdAt, updatedAt
```
