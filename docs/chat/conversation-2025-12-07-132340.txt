  设计方案总结

  我已在 docs/ 目录下创建了 5 个设计文档：

  1. architecture.md - 整体架构

  - 技术栈: 前端 React+Vite+shadcn/ui，CLI 用 Python
  - 核心策略: "本地生成数据 + CI/CD 自动部署"
  - 优势: 数据准确性优先，人工校验后再发布

  2. frontend.md - 前端界面设计

  - 两个核心页面: 总表页面 (/) 和对比页面 (/compare)
  - 四档复杂度: 简单→爱好者→开发者→自定义
  - 交互逻辑: 搜索过滤、列排序、点击查看详情、模型对比
  - 组件规划: ModelTable、CompareView、ModelCard、ColumnConfig 等

  3. cli.md - CLI 数据处理

  - 核心命令: add, fetch, parse, export, update
  - 模块设计: fetcher (获取) → parser (解析) → exporter (导出)
  - 数据源: config.json, tokenizer_config.json, generation_config.json,
  adapter_config.json
  - 缓存机制: 本地缓存配置文件，支持增量更新

  4. schema.md - 字段定义

  - 字段来源映射: 每个字段对应的配置文件和 JSON Path
  - TypeScript 类型: 完整的 ModelInfo 接口定义
  - 复杂度预设: 不同等级显示不同字段
  - 格式化函数: 参数量 (B/M)、上下文长度 (K)、日期等

  5. deployment.md - 部署方案

  - GitHub Actions: 自动构建和部署到 Pages
  - 工作流程: 本地更新数据 → git push → 自动部署
  - SEO 优化: Meta 标签、Sitemap、预渲染建议
  - 故障排除: 常见问题和解决方案

  ---
  与原有设计的主要调整

  1. 前端框架: Next.js → Vite (纯静态更简单)
  2. UI 库: Material Design → shadcn/ui (更现代)
  3. CLI 语言: 从 JS 改为 Python (如你所愿)
