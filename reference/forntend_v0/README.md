# 开源模型参数对比平台

一个纯前端的开源大模型参数综合对比平台，帮助开发者快速了解和选择合适的基础模型。

## 功能特性

### 一期功能 - 模型参数浏览与查询

#### 主表格功能
- **完整的模型数据展示**：展示 15+ 个关键参数列
  - 发布时间（精确到日）
  - 模型参数量（自动格式化为 B/M/T）
  - 基座模型
  - 输入/输出模态
  - 上下文长度
  - Embedding 大小
  - 位置编码形式
  - 架构信息
  - 量化支持等

- **智能搜索**：支持按名称、基座、提供者搜索

- **多列排序**：点击列头进行升序/降序排序

- **灵活的列自定义**：自由选择显示或隐藏哪些列

- **4档复杂度预设**
  - 🟢 **简单**：仅显示基础 4 列（名称、发布时间、参数量、上下文长度）
  - 🟡 **爱好者**：显示 7 列（增加基座、输入模态、embedding等）
  - 🔴 **开发者**：显示 14 列（完整的技术参数和架构信息）
  - ⚙️ **自定义**：显示所有可用参数（16 列）

- **点击查看详情**：点击任意表格行，查看该模型的完整详细信息

### 二期功能 - 模型对比

#### 模型选择器
- 搜索和选择多个模型进行对比
- 复选框快速选中/取消选中
- 实时搜索过滤
- 显示模型的基本信息（名称、提供者、基座）

#### 对比表格
- **横向对比展示**：多个模型并排显示参数
- **复杂度控制**：在对比视图中也可以切换 4 档复杂度
- **列配置面板**：动态选择要显示的参数列
- **模型移除功能**：从对比中快速移除某个模型
- **值格式化**：数字、日期、数组等自动格式化显示
- **响应式设计**：水平滚动查看所有列

### 通用特性

#### UI 设计
- Material Design 风格设计
- 完整的亮暗主题支持
- 流畅的过渡动画
- 响应式布局（移动端友好）

#### 数据持久化
- 模型数据本地存储（localStorage）
- 列配置本地存储
- 自动从本地加载用户配置

#### 导航
- 一期和二期功能之间的便捷导航
- 返回列表的快速按钮

## 技术栈

- **框架**：Next.js 16+ (App Router)
- **UI 组件**：shadcn/ui
- **样式**：Tailwind CSS v4
- **数据存储**：浏览器 LocalStorage
- **类型系统**：TypeScript

## 使用指南

### 一期：浏览和搜索模型

1. **启动应用**：在主页查看所有模型的表格
2. **搜索**：使用顶部搜索框按名称、基座或提供者过滤
3. **排序**：点击列头进行排序
4. **调整复杂度**：选择"简单""爱好者""开发者"或"自定义"预设
5. **自定义列**：点击"列配置"选择要显示的参数
6. **查看详情**：点击任意表格行查看完整的模型信息

### 二期：对比多个模型

1. **进入对比模式**：点击导航栏的"对比模型"按钮
2. **选择模型**：在"选择要对比的模型"区域搜索并选中至少 2 个模型
3. **查看对比**：自动生成包含所有选中模型的对比表格
4. **调整复杂度**：使用预设按钮切换显示的参数数量
5. **配置列**：点击"显示列配置"自定义要对比的参数
6. **移除模型**：点击模型名称旁的 ✕ 按钮移除某个模型

## 关键参数说明

| 参数 | 说明 | 单位 |
|------|------|------|
| **参数量** | 模型的总参数数 | B(十亿)/M(百万)/T(万亿) |
| **发布时间** | 模型发布日期 | YYYY/MM/DD |
| **基座模型** | 该模型的基础模型或系列 | 文本 |
| **输入模态** | 支持的输入类型 | text/image/audio/video 等 |
| **输出模态** | 支持的输出类型 | text/image/audio 等 |
| **上下文长度** | Token 窗口大小 | K(千)/M(百万) |
| **Embedding 大小** | 向量嵌入维度 | 数值 |
| **位置编码** | 位置编码方式 | RoPE/Alibi/绝对编码 等 |
| **架构** | 模型架构类型 | Decoder-only/Encoder-Decoder 等 |
| **MoE 架构** | 是否使用稀疏专家混合 | 是/否 |
| **量化支持** | 支持的量化格式 | int8/int4/fp16/fp8 等 |

## 开发和部署

### 本地开发

\`\`\`bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问应用
# 一期：http://localhost:3000
# 二期：http://localhost:3000/compare
\`\`\`

### 构建和部署

\`\`\`bash
# 生产构建
npm run build

# 启动生产服务器
npm start
\`\`\`
