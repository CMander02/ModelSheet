# ModelSheet 项目架构设计

## 1. 项目概述

ModelSheet 是一个开源模型参数速查与对比工具，通过自动获取 HuggingFace 上模型的配置文件，解析并展示模型的核心参数，帮助用户快速了解和比较不同模型。

## 2. 技术栈选型

### 前端
- **框架**: React + Vite (非 Next.js，纯静态部署)
- **UI 组件库**: shadcn/ui + Tailwind CSS
- **状态管理**: React useState + localStorage
- **构建工具**: Vite
- **部署**: GitHub Pages

### CLI 数据处理
- **语言**: Python 3.13+
- **HTTP 客户端**: httpx (异步支持)
- **数据格式**: JSON
- **包管理**: uv

## 4. 工作流程

### 数据更新流程 (本地操作)

```
1. 维护 models.yaml     →  添加/更新模型 ID 列表
2. 运行 CLI: fetch      →  从 HuggingFace 下载配置文件
3. 运行 CLI: parse      →  解析配置文件，提取字段
4. 运行 CLI: export     →  生成 models.json
5. 人工校验             →  检查数据准确性
6. git commit & push    →  触发 GitHub Actions 部署
```

### 部署流程 (CI/CD 自动)

```
1. 检测 push 到 main 分支
2. 安装依赖: pnpm install
3. 构建前端: pnpm build
4. 部署到 GitHub Pages
```

## 6. 核心设计原则

### 6.1 数据准确性优先
- 所有数据本地生成，人工校验后再推送
- 不在 CI 环境调用 LLM，避免幻觉导致的错误数据
- 优先使用 config.json 等结构化配置文件

### 6.2 纯静态部署
- 前端为纯静态 SPA，无需后端服务
- 所有数据以 JSON 文件形式存储在仓库中
- GitHub Pages 免费托管

### 6.3 简单可维护
- CLI 使用 Python，降低理解和开发门槛
- 前端使用主流技术栈，易于扩展
- 文档清晰，便于协作开发
