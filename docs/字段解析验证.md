## 无法从配置文件获取的字段

以下字段**无法**直接从 HuggingFace 配置文件中获取：

| 字段 | 说明 | 可能的获取方式 |
|------|------|----------------|
| **技术报告链接** | 论文/报告 URL | 从 tags 中提取 `arxiv:xxxx`，转换为 URL |
| **输入模态** | text/image/audio 等 | 需从 tags 或 pipeline_tag 推断 |
| **输出模态** | text/image/audio 等 | 需从 tags 或 pipeline_tag 推断 |
| **Parallel Layer 类型** | serial/parallel | 配置文件中无此信息 |
| **isPreNorm** | 是否使用 Pre-Norm | 配置文件中无此信息（大部分现代模型默认 Pre-Norm） |
| **aspect ratio** | 宽高比 | 非标准字段，需自定义计算 |

### 可能的解决方案

1. **技术报告链接**: 从 API 返回的 `tags` 中提取 `arxiv:` 前缀的标签
   - Qwen3-8B: `arxiv:2309.00071`, `arxiv:2505.09388` → `https://arxiv.org/abs/2309.00071`
   - DeepSeek-R1: `arxiv:2501.12948` → `https://arxiv.org/abs/2501.12948`

2. **输入/输出模态**: 从 `pipeline_tag` 推断
   - `text-generation` → 输入: text, 输出: text
   - `text-to-image` → 输入: text, 输出: image
   - 可结合 tags 中的 `vision`, `audio` 等关键词

3. **isPreNorm**: 现代 Transformer (2020+) 几乎全部使用 Pre-Norm，可设为默认值 `true`

4. **Parallel Layer**: 无法自动检测，需要人工标注或查阅论文

## 总结

### 可直接解析的字段 (31 个字段中的 28 个)

| 类别 | 数量 | 字段 |
|------|------|------|
| Metadata | 7 | id, name, provider, huggingfaceUrl, createdAt, updatedAt, downloads |
| Direct | 11 | architecture, vocabSize, numLayers, numHeads, numKvHeads, hiddenSize, embeddingDim, intermediateSize, activation, normEps, attentionDropout |
| Logic | 6 | contextLength, totalParameters, activeParameters, isMoe, normType, positionEncoding |
| Calc | 2 | mlpFactor, gqaRatio |
| Tokenizer | 3 | eosToken, bosToken, hasChatTemplate |
| FileCheck | 1 | isAdapter |
| MoE | 5+ | numExperts, numExpertsPerToken, numSharedExperts, firstKDenseReplace, moeIntermediateSize |

### 需要额外逻辑或人工标注的字段 (3 个)

1. **arxivUrl** (技术报告链接) - 可从 tags 提取
2. **inputModality / outputModality** - 可从 pipeline_tag 推断
3. **isPreNorm / parallelLayer** - 需人工标注或默认值

### 建议新增字段

基于 DeepSeek-R1 的配置，建议考虑新增：

- `ropeScalingType`: RoPE 扩展类型 (yarn, linear, dynamic 等)
- `quantMethod`: 量化方法 (fp8, int8, int4 等)
- `headDim`: 注意力头维度
